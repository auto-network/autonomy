When NOT to invent a new endpoint
  • The data lives in a Setting and you have the key — direct read.
  • You need enumeration — .all(), not a custom listing endpoint.
  • You need to react to changes — .onChange(cb), not polling.
  • You need typed UI state — Schema.alpine(), not bespoke fetch helpers.
