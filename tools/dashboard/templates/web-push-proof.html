Structural proof

Send one real Web Push

This temporary probe stores nothing. It subscribes this installed web app, sends one encrypted generic message through Apple, and waits for iOS to display it.

  • Secure origin
  • Home Screen app
  • Service worker
  • Push + notifications
  • Permission

  1. On iPhone or iPad, open this page in Safari and choose Add to Home Screen.
  2. Open the new Push Proof icon. Permission must be requested from the button tap below.
  3. Tap Enable and send test, then leave the app. Apple should present the notification.
