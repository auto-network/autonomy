## Mailbox

This workspace can use the organization's mailbox through the `mail-*`
commands: `mail-list`, `mail-read UID`, `mail-wait --to ADDRESS`, and
`mail-send` (each send waits for the operator's approval). Reading is
read-only and needs no approval. The mailbox password is never in this
workspace; the dashboard holds it. Full usage: the `mailbox` skill.
