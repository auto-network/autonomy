# Path: solo knowledge base

For the single developer whose repos you already know. The goal state: a
personal org whose graph holds their working context, searchable from any
future session.

1. The org founded at install (`AUTONOMY_FIRST_ORG`) is their space; no
   further org structure needed today.
2. **Seed by proposal.** Survey their recent work — active repos, recent
   commits, the topics you've been helping with. Draft 5–15 seed notes
   (project overviews, decisions you know they made, current threads) and
   present the LIST for approval before creating any. Propose-not-act is
   the rule; a wrongly-seeded graph is worse than an empty one.
3. Teach by doing: create the approved notes with `graph note`, then run a
   `graph search` for something they'd actually look up, in front of them.
4. Point at the loop: future sessions (theirs and yours) read and write
   this same graph. The habit to seed: "worth remembering → note it."

Done when: their graph returns useful results for two real queries, and
they know how to add a note themselves.
