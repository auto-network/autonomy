# Path: agent workbench

For the user who wants what you are: agents working their repositories,
with persistent memory and a work ledger.

1. Connect their most active repository as a workspace (dashboard →
   Workspaces). Sessions get an isolated worktree on a session branch;
   merges land through the dashboard's fast-forward path.
2. Provision session credentials (primer §7) — the node runs Claude Code
   or Codex sessions in containers using the credential the user already
   has. Their quota pays for sessions; say so.
3. Launch a first session from the dashboard and let the user watch it in
   the session viewer — the handover moment the primer aims at.
4. Show the ledger: work tracked as beads, sessions linked to what they
   did, the graph accumulating what was learned.

Done when: one real session ran against their repo and they watched it
live in the browser.
